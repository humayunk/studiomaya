# Homepage messaging v3 — founder-first

Issue: humayunk/studiomaya#2 · July 2026

## Problem

The v2 hero ("I build products. Some mine, some for founders.") is an identity statement. A founder landing on the page has to work out whether Humayun is hireable, for what, and at what price. The mine/yours framing also conflates the studio's two engines (client builds and own products) in the one slot on the page that should sell.

## Research basis

Studied ~25 live one-person studio sites in three buckets: productized solo studios (DesignJoy, RocketMVP, Aceternity, Designpixil, mazur.design), craft-led design engineers (Rauno Freiberg, Emil Kowalski, Paco Coursey, oh.studio), and product+client hybrids (Levels, Marc Lou, Corey Haines, Brian Casel, Tom Hirst, Try Hard Studios). Consistent patterns:

1. No successful hero uses mine/yours framing. Heroes sell buyer + speed + category; sections handle the split.
2. Sites that close founder work show offer, fixed price, and delivery time within the first one to two scrolls.
3. Solo-ness is sold as the premium ("you work directly with me"), never disguised as an agency.
4. Own products appear as a proof section with honest specifics, not as a competing offer.
5. Scarcity is anchored to real solo capacity (slots per month, booking window).
6. One low-friction CTA repeated (fit call), never a menu.

Decision: keep one commercial site (studiomaya.io). humayun.xyz stays the personal hub. No two-site split of services vs. products; the confusion is resolved by page structure.

## Changes (index.html only, this pass)

- **Hero:** founder-facing. Buyer (healthcare and AI founders), speed (weeks), fixed price in the hero note with actual numbers. Keep "Design, code, and AI in one head." Availability eyebrow refreshed to August 2026.
- **Section order:** 01 proof marquee → 02 selected work (moved up from 04) → 03 offers → 04 why-me essay ("The build got cheap") → 05 testimonials → 06 products-as-proof → 07 about → final CTA. Numbered eyebrows renumbered.
- **Products section:** reframed as proof of shipping, not a second offer.
- **About:** add direct-access line (no agency, no handoffs, one build at a time).
- **Title/meta:** founder-first, prices implied, no em dashes.

## Out of scope (later passes)

- Design-centric upgrades: work shown bigger, real product screens/motion, craft-grid treatment (Rauno-style) for own products.
- Repricing consideration: Mazur charges $12k for a brand sprint alone; $9k full build is likely underpriced.
- Real founder testimonials refresh; usage numbers for own products when honest ones exist.
